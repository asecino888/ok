# 雷雲音樂律動影像播放器

這是一個可直接用瀏覽器開啟的前端專案（HTML/CSS/JavaScript），可分析音樂音量與重音強度，並依照強弱切換不同亮度的雷雲圖片。

## 功能特色

- 上傳一首音樂檔（例如 `.mp3`、`.wav`）。
- 上傳多張雷雲圖片，依檔名分級亮度（0~4）。
- 使用 Web Audio API (`AnalyserNode`) 分析音訊波形。
- 以 RMS（均方根音量）判斷當前音量強弱。
- 以「瞬時能量 / 近期平均能量」做簡單 beat detection。
- 強重音時短暫顯示最亮閃電圖。
- 圖片切換採淡入淡出效果。
- 視覺舞台固定 `16:9`，圖片鋪滿畫面（`object-fit: cover`）。
- 提供參數控制：播放/暫停、音量敏感度、閃電門檻。

```text

├── index.html

├── script.js

└── assets/
    └── images/
        ├── 0_dark.png
        ├── 1_low_glow.png
        ├── 2_mid_glow.png
        ├── 3_high_glow.png
        └── 4_lightning.png
```

> `assets/images/` 為預設建議放圖位置；頁面開啟時會自動嘗試載入此資料夾中的 0~4 圖片。
> 若未自動載入成功，可用「選擇雷雲圖片（可多選）」手動上傳本機圖片。

## 圖片命名規則（重要）

請使用以下命名邏輯（副檔名可為 png/jpg/jpeg/webp）：

- `0_dark.png`：最暗
- `1_low_glow.png`：微亮
- `2_mid_glow.png`：中亮
- `3_high_glow.png`：很亮
- `4_lightning.png`：最亮（大閃電）

程式會讀取檔名開頭的數字 `0~4` 來判斷亮度等級。

---

## 使用方式

1. 下載或複製此專案到本機。
2. 把 0~4 圖片放進 `assets/images/`（可選，若要自動載入建議先放好）。
3. 直接雙擊 `index.html`（或用瀏覽器開啟）。
4. 在頁面中：
   - 點「選擇音樂」上傳 1 首音樂。
   - 若你沒有使用預設資料夾自動載入，請點「選擇雷雲圖片（可多選）」一次選 0~4 等級圖片。
   - 點「播放」開始。

## 參數調整建議

### 1) 音量敏感度（Volume Sensitivity）

- 數值越高：同樣音量下更容易切到亮圖。
- 數值越低：畫面變化較保守，偏暗。

建議範圍：
- 音樂整體較小聲時：`1.4 ~ 2.2`
- 音樂動態很大時：`0.8 ~ 1.4`

### 2) 閃電門檻（Lightning Threshold）

- 用來控制判定「重音」的嚴格程度（瞬時能量相對平均值的倍率）。
- 數值越低：較容易觸發閃電。
- 數值越高：只有很強重音才觸發。

建議範圍：
- 想要頻繁閃電：`1.2 ~ 1.6`
- 想要明顯鼓點才閃：`1.7 ~ 2.3`

## 技術說明

- 音訊分析：
  - `AudioContext`
  - `MediaElementAudioSourceNode`
  - `AnalyserNode`（`getByteTimeDomainData`）
- 音量估算：
  - RMS = `sqrt(mean(sample^2))`
- 節奏觸發：
  - 以指數平滑方式維護近期平均能量
  - 當 `瞬時能量 / 平均能量` 高於門檻，判定 beat
- 即時更新：
  - `requestAnimationFrame` 每幀更新亮度等級與圖片

## 注意事項

- 瀏覽器對本機檔案播放政策不同，第一次播放可能需要手動點擊按鈕啟動音訊（本專案已透過按鈕互動啟動）。
- 若未上傳完整 0~4 圖片，程式會自動使用最接近可用等級的圖片。
- 建議使用最新版 Chrome / Edge / Firefox。
